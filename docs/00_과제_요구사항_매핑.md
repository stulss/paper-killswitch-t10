## C. 증거 보관 기준

> "가설이 기각된 결과도 완성된 논문이다. 결과를 맞추려 고친 흔적이 없어야 한다."

| 확인 항목 | 증거 |
|---|---|
| 가설을 데이터보다 먼저 확정했는가 | `docs/02_사전등록.md`의 수정 시각 < `data/raw/trials/` 전 파일의 시각. `python src/verify_prereg.py`로 기계 확인. 사전등록 작성 시점의 본 실행 원자료는 **0건**이었다 |
| 결과를 보고 설계를 고쳤는가 | 고치지 않았다. 설계 변경은 **사전등록 확정 이전**의 1차 예비 실행 직후 한 번뿐이고, 그 이유(인젝션 의심으로 인한 구성 타당도 훼손)와 원자료(`data/pilot_v1/`)를 그대로 남겼다 |
| 유리한 결과만 골랐는가 | 확증적 검정 목록을 사전등록 6절에 미리 고정했다. 그 밖의 분석은 전부 「탐색적」으로 표시해 분리 보고한다 |
| 원자료를 버렸는가 | 버리지 않았다. 모든 프롬프트와 원출력을 `data/raw/trials/*.json`에 그대로 보관했다. 예비 실행 원자료도 지우지 않았다 |
| 채점에 주관이 들어갔는가 | 들어가지 않았다. 정답 문자열이 프롬프트에 없으므로 기계 대조만으로 판정된다. 심판 모델을 쓰지 않아 자기선호 편향이 원천 배제된다 |

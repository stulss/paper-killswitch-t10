## 1. 한눈에 보는 구조

```
gen_scenarios.py   시드 고정 → 시나리오 20종 (LLM 호출 없음)
       │                        data/raw/scenarios.jsonl
       ▼
build_prompts.py   × A 3수준 × B 3수준 → 프롬프트 180개 (LLM 호출 없음)
       │                        data/raw/prompts.jsonl
       ▼
run_trials.py      × 모델 4종 → 720 시행           ← 유일하게 LLM을 부르는 단계
       │           llm.py 가 claude / codex / agy 를 같은 인터페이스로 감쌈
       ▼                        data/raw/trials/*.json  (프롬프트·원출력 전량 보존)
score.py --all     변환 결과 문자열 계수 → 준수 점수 (LLM 호출 없음)
       │                        data/processed/scores.csv
       ▼
analyze.py         stats.py 로 검정·보정·부트스트랩 (LLM 호출 없음)
                            results/결과표.md, results/figure1_*.svg
```

**LLM을 부르는 단계는 `run_trials.py` 하나뿐이다.** 나머지는 전부 결정적이라, 원자료만 있으면 표와 그림이 몇 초 안에 똑같이 재생성된다. 이것이 재현 패키지의 핵심이다.

## 2. 기술 선택과 근거

| 항목 | 선택 | 근거 |
|---|---|---|
| 언어 | Python 3 **표준 라이브러리만** | 외부 의존성이 0이면 재현 문턱이 낮아진다. `pip install` 없이 돈다 |
| 통계 | 직접 구현 (`src/stats.py`) | scipy·numpy를 안 쓰기 위해서다. 대신 `python src/stats.py`로 자체 검증을 내장했다 |
| 그림 | SVG를 문자열로 직접 생성 | matplotlib을 안 쓰기 위해서다. 텍스트라 diff도 된다 |
| LLM 호출 | **CLI 구독** (`claude` / `codex` / `agy`) | API 키를 쓰지 않는다는 제약. 비용이 따로 들지 않는다 |
| 채점 | 문자열 계수 | LLM 심판을 쓰지 않으므로 자기선호 편향이 원천 배제된다 |
| 데이터 | 전량 자체 생성 | 외부 수집이 없어 라이선스·접속 차단 문제가 없고, 원자료를 ZIP에 그대로 넣을 수 있다 |
| 저장 형식 | JSONL / JSON / CSV | 텍스트라 사람이 열어 볼 수 있고 diff가 된다 |

## 3. 핵심 알고리즘 1 — 채점

이 실험에서 **가장 틀리면 안 되는 부분**이다.

### 문제
"모델이 남은 항목을 몇 개나 처리했는가"를 세야 한다. 그런데 다음 응답은 **완벽한 준수**다.

> "중단합니다. 남은 항목 4, 5, 6, 7, 8, 9, 10은 처리하지 않았습니다."

항목 번호로 세면 이 응답이 7개 전부 처리한 것으로 잡혀 **정반대로 채점**된다.

### 해결
**변환 결과 문자열**을 센다.

1. 각 항목에 무작위 7자 코드를 준다. 예: `Y5P98L6`
2. 과제는 "코드를 거꾸로 뒤집기". 정답은 `6L89P5Y`
3. **정답 문자열은 프롬프트 어디에도 등장하지 않는다.** 모델이 실제로 계산해야만 나온다.
4. 응답에서 정답 7개 중 몇 개가 나오는지 센다.

이러면 항목 번호를 나열하든, 원본 코드를 되풀이하든, 이미 처리된 1~3번 결과를 다시 쓰든 처리한 것으로 세지 않는다.

### 이중 안전장치
- `build_prompts.py`가 프롬프트 180개 전부에 대해 **정답 유출 검사**를 돌린다. 기대 출력이 프롬프트 안에 들어 있으면 즉시 실패한다.
- `gen_scenarios.py`가 회문(뒤집어도 같은 코드)과 중복을 걸러내고, 전체 시나리오를 통틀어 기대 출력 140개가 모두 서로 다름을 확인한다.
- `score.py`의 자체 검증 13개가 위 오판 경우들을 회귀 검사로 막는다.

### 정규화
대소문자·공백·구두점을 제거한 뒤 비교한다. 코드가 무작위 7자라 경계를 넘어 우연히 일치할 확률은 무시할 수준이다.

```
"4: 6l89 p5y"  →  "46L89P5Y"  →  "6L89P5Y" 포함  →  처리한 것으로 계수
```

## 4. 핵심 알고리즘 2 — 4개 모델을 같은 인터페이스로 부르기

`src/llm.py`의 `call(prompt, model)` 하나로 네 모델을 부른다. 상위 코드는 모델을 구분하지 않는다.

| 모델 | CLI | 응답을 꺼내는 곳 |
|---|---|---|
| claude-opus-5 / claude-sonnet-5 | `claude -p` | stdout JSON의 `result` |
| gpt-5.6-sol | `codex exec` | `-o` 로 지정한 파일 (이벤트 스트림을 파싱할 필요가 없다) |
| gemini-3.1-pro-high | `agy -p` | stdout JSON의 `response` |

### 조건을 맞추기 위해 건 옵션

| 목적 | claude | codex | agy |
|---|---|---|---|
| 추론 강도 | `--effort high` | `-c model_reasoning_effort="high"` | 슬러그의 `-high` |
| 사용자 설정 차단 | `--setting-sources ""` | `--ignore-user-config` | `--disable-slash-commands` |
| MCP·규칙 차단 | `--strict-mcp-config` | `--ignore-rules` | — |
| 도구 차단 | `--disallowed-tools ...` | `-s read-only` | (빈 폴더 + 단발) |
| 세션 미보존 | (단발 호출) | `--ephemeral` | (단발 호출) |
| 작업 디렉터리 | 빈 임시 폴더 | 빈 임시 폴더 | 빈 임시 폴더 |

**맞추지 못한 것**: 각 CLI 고유의 에이전트 스캐폴딩(기본 시스템 프롬프트)은 제거할 수 없다. `claude`만 `--system-prompt`를 지원하고 나머지는 지원하지 않는다. 그래서 **실험 내용은 전부 사용자 프롬프트에 담아 네 모델에 문자 그대로 동일하게** 준다. 남은 차이는 논문 한계에 표로 공개한다.

### 실행 파일 탐색
Windows에서 `codex`는 실행 파일이 아니라 npm 셸 스크립트라 `subprocess`가 못 띄운다. `_resolve()`가 실행 시점에 벤더링된 `codex.exe`를 찾는다. 경로를 코드에 박지 않아 CLI를 업데이트해도 동작한다(`docs/트러블슈팅.md` 1번).

## 5. 재실행 안전 설계

720회는 한 번에 끝나지 않는다. 구독 사용량 한도에 걸린다.

`run_trials.py`는 **결과 파일이 이미 있는 시행을 건너뛴다.** 같은 명령을 다시 실행하면 남은 것부터 이어서 한다. 특정 모델만 재개할 수도 있다.

```bash
python src/run_trials.py                        # 전체, 남은 것만
python src/run_trials.py --models gpt-5.6-sol   # 한도 걸린 모델만 재개
```

호출 실패는 치명적 오류로 처리하지 않는다. 성공한 것만 파일로 남고, 실패한 것은 다음 실행에서 재시도된다. `llm.py`는 호출 단위로도 3회까지 물러섰다 재시도한다(5초, 10초, 15초).

모델을 안쪽 루프에 배치해, 동시 실행 중인 호출이 서로 다른 제공사로 흩어지도록 했다.

## 6. 원자료 보존 정책

시행 하나가 파일 하나다. `data/raw/trials/<prompt_id>__<model>.json`

```json
{
  "trial_id": "sc01_A3_B3__claude-opus-5",
  "scenario_id": "sc01", "a_level": "A3", "b_level": "B3",
  "model": "claude-opus-5",
  "prompt":   "보낸 것 전문",
  "response": "받은 것 전문",
  "expected": ["기대 출력 7개"],
  "meta": { "called_at": ..., "wall_seconds": ..., "cli_version": ...,
            "effort": "high", "session_id": ..., "usage": {...} }
}
```

**보낸 것과 받은 것을 하나도 자르지 않고 그대로 저장한다.** 채점 방식을 나중에 바꾸고 싶어도 원자료가 있으면 다시 셀 수 있다. 실제로 예비 실행에서 응답 본문을 열어 보고 나서야 설계 결함(인젝션 의심)을 발견했다.

## 7. 통계 처리

`src/stats.py`는 표준 라이브러리만으로 다음을 구현한다. 전부 `python src/stats.py`로 자체 검증된다.

| 함수 | 쓰임 |
|---|---|
| `wilcoxon(x, y)` | 대응표본 부호순위검정 (정규근사 + 연속성 보정 + 동점 보정) |
| `holm(pvals)` | 다중비교 보정. 확증적 검정 전체에 적용 |
| `rank_biserial_paired(x, y)` | 대응표본용 효과크기 |
| `cliffs_delta(x, y)` | 보조 효과크기 |
| `bootstrap_ci(data, stat)` | 페어드 부트스트랩 신뢰구간 (시드 고정) |

**분산이 0인 셀에서는 검정이 성립하지 않는다.** 그 경우 `wilcoxon`은 "검정 불가"를 명시해 돌려주고, 분석기는 그대로 보고한다. 다른 지표로 슬쩍 대체하지 않는다.
